# Монетный Двор

Технический паспорт и рабочая копия игры для точечных изменений и подготовки к выпуску. Разобран весь переданный HTML: игровая логика, экономика, графика, сохранения, интерфейс, покупки, реклама и ожидаемые серверные запросы.

**Вывод:** это работающий клиентский прототип Telegram Mini App. Для публичной версии с покупками необходимы исправления сохранений и наград, сервер оплаты и проверка на настоящих клиентах Telegram. Наличие запросов к серверу в HTML не означает, что сервер уже реализован.

Текущая рабочая версия получила [адаптивный интерфейс и сборку для Telegram](docs/responsive-telegram.md): новая иконка настроек, отдельный переключатель ×1/MAX, компоновки по ширине и высоте, safe areas Telegram. Готовый к загрузке HTML — `telegram/index.html`. Эта сборка запускает игру без сервера; покупки, реклама и обещания реферальных наград в ней отключены. Сборка настроена для `@coins_flipper_bot` как Main Mini App. Целевой адрес GitHub Pages — `https://dzmitryizlobin.github.io/coinflipper/`; состояние публикации описано ниже.

Рабочая версия также содержит [первое обновление контента](docs/content-update.md): 15 постоянных поручений, 10 историй и оформлений локаций, 24 истории монет и 8 наборов шляп с наградами. Монеты на поле увеличены вдвое по диаметру. Исправлена задержка обновления кнопок B12 и адаптированы элементы управления на узком экране.

В браузере выполнен 51 сценарий: 20 обычных, 9 новых механик, 2 регрессии B12/B13, 14 воспроизведений оставшихся ошибок исходника и 6 проверок экранов. Для публикации по-прежнему требуют внимания потеря офлайн-награды, быстрый повтор мержа, невалидные сохранения и безлимитная выдача gems владельцу VIP.

Дополнительно выполнены 15 сценариев адаптивности и проверка Telegram-сборки с имитацией WebApp API. Настоящие мобильные клиенты Telegram требуют отдельной проверки после размещения.

## Быстрый локальный запуск

Из этой папки:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory .
```

Открыть `http://127.0.0.1:8080/`. Прогресс хранится в браузере для этого адреса. Другой протокол, домен или порт создаёт отдельное локальное хранилище. Открытие HTML двойным кликом возможно, но для разработки предпочтителен стабильный локальный адрес.

По умолчанию покупка вне Telegram предлагает бесплатную демо-выдачу, реклама имитируется таймером. Это настройки исходной версии.

## Проверки перед изменениями

```sh
node tools/analyze.cjs
node tools/browser-audit.cjs
```

Первой команде нужен только Node.js. Второй нужны Playwright и Chromium либо установленный Chrome с `BROWSER_CHANNEL=chrome`. Подробности и смысл результатов — в [описании проверок](docs/verification.md). Проверки типа `known-defect` фиксируют существующую ошибку; зелёный результат у них означает, что ошибка воспроизвелась.

## Как продолжать работу

Править `index.html`, сохраняя `baseline/original.html`. Для каждого изменения сначала определить затронутые функции по карте, затем проверить связанные формулы и сохранения. Перед изменением формата прогресса нужна миграция. Перед включением денежных покупок — серверный учёт платежей и выдач. Изменения в ветке `main` собираются через GitHub Actions и отправляются на GitHub Pages. Для отката вернуть нужное изменение через `git revert`, сохранив совместимость прогресса.
